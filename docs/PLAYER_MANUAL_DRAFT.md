# 영웅스토리 사용자 매뉴얼 초안

이 문서는 향후 정식 게임 매뉴얼의 기반이다. 현재 프로토타입에서 실제로
확인할 수 있는 기능만 기록하며, 아직 구현되지 않은 기능은 포함하지 않는다.

## 1. 지도 생성

1. 개발 설정을 연다.
2. 맵 유형과 맵 등급을 선택한다.
3. 숫자로 된 월드 시드를 입력하고 `이 시드로 생성`을 누른다.
4. 같은 맵 유형, 등급, 시드를 사용하면 같은 기본 세계가 생성된다.
5. `새로운 세계`를 누르면 새로운 시드의 지도가 생성된다.

현재 선택 가능한 맵 유형은 내륙, 대륙, 군도, 고산, 대하천이다.

## 2. 지도 조작

### PC

- 마우스 휠: 확대·축소
- 마우스 왼쪽 짧게 클릭: Hex 또는 캐릭터 선택
- 마우스 왼쪽 드래그: 지도 이동
- 마우스 오른쪽 드래그: 카메라 회전
- 북쪽 버튼: 처음 시점으로 복귀

### 모바일

- 짧게 터치: Hex 또는 캐릭터 선택
- 한 손가락 드래그: 지도 이동
- 두 손가락 조작: 확대·축소와 시점 조정

## 3. Hex 정보 확인

- 빈 Hex를 선택하면 선택 위치에 지형 정보창이 표시된다.
- 같은 Hex를 다시 선택하면 정보창이 닫힌다.
- 캐릭터가 있는 Hex의 정보 버튼을 누르면 캐릭터와 지형 정보가 함께 표시된다.
- 정보창에서 지형 이름과 이동 비용을 확인할 수 있다.

## 4. 캐릭터 이동

1. 행동 가능한 영웅 또는 병사를 선택한다.
2. 밝은 연두색으로 표시된 이동 가능 영역을 확인한다.
3. 원하는 Hex를 선택하면 캐릭터가 해당 위치에 가배치된다.
4. 가배치 상태에서는 이동 가능 영역 안의 다른 Hex로 다시 옮길 수 있다.
5. 경로는 연두색으로, 최종 목적지는 노란색으로 표시된다.
6. 대기 또는 다른 행동을 선택하면 이동이 확정된다.
7. 이동취소를 누르면 원래 위치로 돌아간다.

남은 이동력 숫자는 표시하지 않으며, 이동 가능한 범위로 행동 가능 여부를
확인한다.

## 5. 캐릭터 명령

- 공격: 현재 위치에서 공격 가능한 적을 선택한다.
- 대기: 현재 위치에서 행동을 끝낸다.
- 스킬: 영웅의 제한 횟수 기술을 선택한다. 현재는 시험 기능이다.
- 정보: 캐릭터와 현재 지형 정보를 확인한다.
- 이동취소: 가배치 이동을 취소한다.

행동이 끝난 캐릭터는 색이 약간 비활성화된다. 턴 종료 후 다시 행동할 수 있다.

## 6. 공격

1. 이동 또는 현재 위치 확인 후 공격 명령을 선택한다.
2. 공격할 수 있는 적의 Hex와 아이콘이 표시된다.
3. 적을 선택하면 공격한다.
4. 공격 방법이 둘 이상이면 근접·원거리 등 가능한 방식 중 하나를 선택한다.
5. 공격취소를 누르면 이전 명령창으로 돌아간다.

전투는 세계 지도 위의 짧은 공격과 피격 동작으로 표현된다.

## 7. 지도 안개와 시야

- 영웅의 기본 시야는 주변 4 Hex다.
- 일반 병사의 기본 시야는 주변 3 Hex다.
- 언덕에서는 시야가 1 증가한다.
- 숲에서도 기본 시야가 그대로 유지된다.
- 처음 보는 지역은 흰 구름으로 가려져 있다.
- 현재 보이는 지역은 지형과 적이 선명하게 표시된다.
- 전에 탐험한 지역은 옅은 구름으로 표시되고 현재 적 정보는 보이지 않는다.
- 이동 가배치 중에는 이동할 위치의 시야를 미리 볼 수 있다.
- 이동취소 시 시야도 원래 위치 기준으로 돌아간다.
- 대기나 공격으로 행동을 확정하면 새로 발견한 지형이 탐험 기록에 남는다.

## 8. 주둔지 건설

1. 행동 가능한 영웅을 평원 또는 언덕으로 이동한다.
2. 이동 후 명령창에서 `주둔지 건설`을 선택한다.
3. 첫 번째 주둔지는 수도로 지정되며 기본적으로 주변 4 Hex의 시야를 제공한다.
4. 주둔지를 건설한 영웅은 해당 턴의 행동을 마친다.

영웅이 주둔지와 같은 Hex에 있거나 정식으로 주둔하면 주둔지 시야가 5 Hex로 증가한다.

숲·습지·산악·강·백사장·바다에는 현재 주둔지를 건설할 수 없다.
기존 주둔지와 3 Hex보다 가까운 위치에도 새 주둔지를 건설할 수 없다.
주둔지 Hex를 선택하면 도시 단계와 수도 여부를 확인할 수 있다.

현재 테스트 버전에서는 주둔지를 직접 선택한 뒤 `증축 Lv.2`를 누르면 자원 조건 없이 즉시 소도시로 발전한다. 증축 후 명령창은 바로 닫힌다. 소도시는 Hex를 채우는 목조 성채, 중앙 관청, 주변 목조 건물과 깃발이 달린 감시탑으로 표시된다.

소도시를 다시 선택해 `증축 Lv.3`를 누르면 자원 조건 없이 중도시로 발전한다. 중도시는 돌로 높인 바닥, 석조 성벽과 일정 간격의 돌탑, 성안 중앙의 기와 지휘소와 주변 목조 주택으로 표시된다.

중도시를 선택해 `증축 Lv.4`를 누르면 대도시로 발전한다. 대도시는 중도시의 석조 외곽을 유지하면서, 약 두 배 높이로 솟은 중앙 내성과 주변의 중간 높이 내성 탑들을 배치한다. 중앙 내성은 푸른 원뿔 지붕과 날카로운 첨탑으로 끝나며, 밝은 석재와 높이가 다른 탑을 조합한 독자적인 동화풍 왕성 실루엣으로 표시된다.

## 9. 자원 거점 건설

1. 세력 거점을 선택하고 `건설`을 누른다.
2. 농장·벌목장·광산·시장 중 하나를 선택한다.
3. 거점과 인접한 평원·숲·언덕에 연한 노란색 건설 후보와 망치·톱 표식이 나타난다.
4. 원하는 후보를 선택하면 자원 거점이 즉시 설치된다.

세력 거점 레벨이 1~4일 때 자원 거점을 각각 1~4개까지 건설할 수 있다. 농장은 주변에 바다가 아닌 물 지형이 있으면, 벌목장은 숲에 설치하면, 광산은 언덕에 설치하면 생산량이 2배가 된다. 시장은 다른 시장과 인접하면 두 시장 모두 생산량이 2배가 된다. 보너스 후보에는 건설 전에 `×2`가 표시된다.

## 10. 개발용 확인 기능

- Hex 경계: 전체 Hex 경계를 켜거나 끈다.
- 지도 안개: 안개 표시를 켜거나 꺼 지형 전체와 탐험 상태를 비교한다.
- 지형 범례: 생성된 지형 종류와 개수를 확인한다.
- 캐릭터 표현 비교: 영웅과 병과의 확대·축소 표현을 확인한다.

## 11. 추후 매뉴얼에 추가할 항목

다음 시스템은 규칙 확정과 구현 후 추가한다.

- 탐험 목표물과 사건
- 주둔지 이후의 도시 성장과 시설
- 자원 생산과 연구
- 영웅 영입과 성장
- 세력과 전쟁
- 세계 통일과 다음 단계 계승
- 저장과 불러오기
