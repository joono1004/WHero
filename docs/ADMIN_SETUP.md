# 관리자 카탈로그 관리 설정

`/admin`은 PC용 영웅·보물 관리 화면이다. 첫 관리자 이메일은
`ljhs1004@gmail.com`으로 고정되어 있으며, 이 권한은 브라우저가 아닌
Supabase DB에서 판정한다.

## 최초 1회 설정

1. 게임에서 `ljhs1004@gmail.com`으로 신규 등록하거나 로그인한다.
2. Supabase 프로젝트 **hero-story**의 SQL Editor를 연다.
3. `supabase/schema.sql` 전체를 실행한다.
4. `https://world-in-hero.vercel.app/admin`에 같은 이메일로 로그인한다.

SQL은 다음을 한 번에 만든다.

- 일반 사용자/관리자 역할을 가진 `profiles` 테이블
- 기존 및 이후 `ljhs1004@gmail.com` 계정에만 관리자 권한을 부여하는 트리거
- 공개 상태, 초상 경로, 모든 능력치·특기·스킬을 담는 `hero_catalog` 테이블
- 역사 설명·게임 설명·등급·효과·장착 제한을 담는 `treasure_catalog` 테이블
- 관리자 작업 중인 프레임 정렬값과 게임 반영본을 분리하는 병과 애니메이션 테이블
- 일반 사용자는 공개 영웅 읽기만 가능하고, 관리자는 추가·수정 가능한 RLS 정책
- 장포·위연·서서·관우·조운·제갈량 초기 데이터

## 운영 규칙

- 영웅 ID는 한번 공개된 뒤에는 바꾸지 않는다.
- 삭제 대신 `비공개`로 전환한다. 기존 저장 데이터와의 연결을 보호하기 위함이다.
- `첫 영웅`으로 설정한 영웅만 새 게임의 최초 영웅 선택에 나타난다.
- `영입 가능` 영웅은 카탈로그에 공개되지만, 실제 영입 루트가 추가되기 전까지는
  새 게임 선택 목록에 나타나지 않는다.
- 반영한 내용은 다음 게임 접속/새로고침 후 영웅 선택 및 영웅 정보 화면에 적용된다.

## 보물 운영 규칙

- 보물은 일반 장비가 아니라, 실제 역사 기록·유물·문헌을 바탕으로 한 단품이다.
- 무기만 보병·기병·궁병·책사 장착 제한을 설정한다. 방어구·탈것·기타는 모든 영웅이 장착할 수 있다.
- 현재 카탈로그에는 24개 보물이 등록되어 있다. 보물 획득·가방 지급·장착 효과 계산은 이후 전투 및 탐색 보상 작업에서 연결한다.
- `보물정보`에서 수정한 내용은 공개 상태일 때 다음 접속/새로고침부터 게임 카탈로그에 반영된다.

## 병과 프레임 정렬 운영 규칙

- `병과정보`에서 이미지를 끌어 프레임 위치를 맞춘 뒤 `이 방향 작업 저장`을 누른다.
  이 작업본은 플레이어에게 보이지 않는다.
- 같은 동작의 다음 프레임을 맞출 때는 이전 프레임을 `현재 프레임을 기준으로 고정`으로
  지정한다. 다음 프레임에서는 기준 이미지가 반투명으로 남아 있어 발 위치와 실루엣을
  비교할 수 있다.
- 여섯 방향과 모든 동작의 검토가 끝났을 때만 `게임 반영`을 누른다. 이 버튼은 작업본을
  플레이어용 공개 데이터로 복사한다.
- 이 기능을 처음 운영 서버에서 사용하기 전에는 최신 `supabase/schema.sql` 전체를 SQL
  Editor에서 다시 실행한다. 기존 영웅·보물 데이터는 `on conflict do nothing` 규칙으로
  유지되며, 병과 애니메이션 테이블과 정책만 추가된다.
