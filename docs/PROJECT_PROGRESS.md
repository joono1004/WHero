# World in Hero 개발 기록

마지막 갱신: 2026-08-03

이 문서는 지금까지 확정된 기획과 실제 프로토타입 구현 상태를 구분해 기록한다.
검토 중인 아이디어는 확정 규칙으로 취급하지 않는다.

## 1. 게임의 현재 방향

- 브라우저에서 실행되는 모바일 우선 턴제 전략 게임이다.
- 내부 이동과 전투 판정은 pointy-top Hex를 사용한다.
- Hex 경계는 이동 동선을 알 수 있도록 화면에 표시한다.
- 지형 그래픽은 Hex 경계에서 잘려 보이지 않고 주변 지형과 자연스럽게 이어져야 한다.
- 일반 전투는 별도 전투 화면 없이 세계 지도 위에서 진행한다.
- 영웅의 특별한 기술만 추후 별도 액션 영상이나 오버레이를 사용할 수 있다.
- 영웅과 일반 병사는 서로 독립된 유닛이다. 병사 부대에 영웅을 겹쳐 배치하지 않는다.
- 장기적으로는 작은 랜덤 세계에서 시작해 통일 후 더 큰 세계로 진출하는 단계형 진행을 목표로 한다.
- 과금, 계정, 클라우드 저장, 소셜 기능은 핵심 게임 루프가 검증된 뒤에 다룬다.

## 2. 월드 생성 엔진

### 확정 및 구현됨

- 정수 시드를 사용하며 같은 시드와 생성 조건은 같은 지도를 만든다.
- 2.5D 지도와 자연스럽게 연결되는 지형 군락을 사용한다.
- Hex 전체 경계를 켜고 끌 수 있다.
- 지도는 마우스와 모바일 터치 조작을 고려한다.
- 확대·축소, 이동, 회전, 초기 시점 복귀를 지원한다.
- 지형과 캐릭터는 카메라 회전 시 같은 공간 좌표에 유지된다.
- 맵 생성 중에는 현재 생성 조건을 보여주는 로딩 화면을 표시한다.

### 맵 등급

| 등급 | 권장 세력 수(사용자 포함) | 현재 크기 |
|---|---:|---:|
| 미니 | 2 | 30×26 |
| 소형 | 3 | 36×33 |
| 중형 | 4 | 42×38 |
| 대형 | 5 | 47×42 |
| 거대 | 6 | 52×46 |
| 초거대 | 7 | 57×49 |
| 월드 | 8 | 62×52 |

현재 프로토타입 검증에는 소형 또는 중형을 주로 사용한다.

### 맵 유형

- 내륙: 바다가 없이 넓게 이어진 육지
- 대륙: 하나의 큰 대륙과 외곽 바다
- 군도: 크기와 형태가 서로 다른 여러 섬
- 고산: 바다 없이 산맥·고원·협곡 중심, 습지는 적게 생성
- 대하천: 바다 비율 5% 미만, 본류 2개 이상과 합류 구간 포함

### 현재 지형 목록

- 평원·일반 육지
- 백사장
- 바위 해안·해안 절벽
- 얕은 바다
- 깊은 바다
- 강
- 숲
- 습지
- 언덕
- 산악
- 설산 정상 표현

### 지형 표현 원칙

- 숲은 여러 Hex가 연결되면 하나의 큰 군락처럼 표현한다.
- 작은 숲은 나무 한두 그루로 표현한다.
- 언덕은 평원과, 산악은 언덕과 자연스럽게 이어지게 한다.
- 육지 끝은 생성 단계부터 자연스러운 해안 형태를 가진다.
- 백사장은 모든 해안에 생성하지 않고 일부 구간에만 생성한다.
- 작은 내륙 호수에는 넓은 백사장을 만들지 않는다.
- 얕은 바다와 깊은 바다는 색과 수심감이 구분되어야 한다.
- 강은 산악 또는 큰 호수에서 시작해 바다로 이어지고 하류로 갈수록 넓어진다.
- 강은 지형 위에 선을 올리는 방식이 아니라 지형을 가르며 흐르는 형태로 표현한다.

## 3. 캐릭터와 부대 표현

### 아트 방향

- 귀여운 전략 게임풍 2.5D 캐릭터를 사용한다.
- 역사 인물의 상징적인 무기, 갑옷, 색상과 병과 특징은 분명하게 유지한다.
- 현재 영웅 시각 샘플: 관우(기병), 황충(궁병), 위연(보병), 조운(창병)
- 현재 일반 병과: 보병, 궁병, 기병

### 확대 단계 표현

- 가까이에서는 영웅과 대표 병사의 전신 캐릭터를 표시한다.
- 멀리서는 영웅은 얼굴 중심 원형 초상화로 표시한다.
- 멀리서는 병사는 검·활·말 형태의 병과 문양으로 표시한다.
- 영웅 외곽선과 원형 초상 테두리는 등급별 색상으로 표시한다.
- 일반 병사는 등급 외곽 효과를 사용하지 않는다.
- 캐릭터의 발은 해당 Hex 안쪽 하단 기준에 맞춰 지면에 서 있는 것처럼 표시한다.
- 캐릭터가 있는 Hex는 투명한 영역과 테두리로 식별 가능하게 한다.

## 4. 이동 규칙과 조작 흐름

### 지형 이동 비용

| 지형 | 이동 비용 |
|---|---:|
| 평원·일반 육지 | 1 |
| 숲 | 2 |
| 언덕 | 2 |
| 강 | 2 |
| 백사장 | 2 |
| 바위 해안 | 2 |
| 얕은 바다 | 2 |
| 습지 | 3 |
| 산악 | 이동 불가 |
| 깊은 바다 | 이동 불가 |

- 이동 가능 범위는 밝은 형광 연두색으로 표시한다.
- 선택한 목적지까지의 저비용 경로를 연두색 계열로 표시하고 목적지는 노란색으로 강조한다.
- 남은 이동력 수치는 사용자 화면에 표시하지 않는다.
- 지형 정보창에서는 해당 Hex의 이동 비용을 확인할 수 있다.

### 이동 상태

1. 영웅 또는 병사를 선택하면 이동 가능 범위가 표시된다.
2. 이동 가능 Hex를 선택하면 해당 위치에 가배치된다.
3. 가배치 중에는 같은 이동 가능 범위 안에서 위치를 다시 바꿀 수 있다.
4. 가배치 후 캐릭터 아래에 세로형 명령창이 표시된다.
5. 이동취소를 누르면 선택 이전 위치와 상태로 복구된다.
6. 범위 밖 지형이나 다른 캐릭터를 확인해도 가배치 상태는 유지된다.
7. 대기를 누르거나 공격·기술을 실행하면 행동이 확정된다.
8. 행동을 마친 캐릭터는 약한 비활성 색으로 표시되고 다음 턴에 다시 활성화된다.

### 현재 명령창

- 공격: 공격 가능한 대상이 있을 때만 표시
- 대기: 현재 위치에서 행동 종료
- 스킬: 영웅에게만 표시하며 맵별 사용 횟수 제한 예정
- 정보: 캐릭터 정보와 현재 지형 정보 표시
- 이동취소: 가배치 상태일 때 표시
- 주둔지 건설: 영웅이 건설 가능한 지형에 있을 때만 표시

## 5. 전투 상호작용

- 공격 버튼을 누르면 공격 가능한 적의 Hex와 공격 아이콘을 표시한다.
- 적을 선택해야 실제 공격이 실행된다.
- 공격 방식이 하나면 바로 실행한다.
- 근접과 원거리처럼 가능한 방식이 둘 이상이면 허용된 방식만 선택창에 표시한다.
- 일반 공격은 세계 지도 위의 짧은 공격·피격 동작으로 표현한다.
- 영웅 스킬과 회복 기술은 현재 기초 구조만 있으며 세부 규칙은 추후 정의한다.

## 6. 안개와 탐험 시야

### 3단계 상태

- 현재 시야: 지형과 현재 유닛을 선명하게 표시
- 탐험 완료: 지형은 옅은 구름 아래 보이지만 현재 적 정보는 숨김
- 미탐험: 흰 구름으로 지형과 적을 가림

### 시야 규칙

| 대상 | 기본 시야 |
|---|---:|
| 영웅 | 3 Hex |
| 일반 병사 | 2 Hex |

- 언덕 위에서는 시야 +1
- 숲에서는 시야 -1
- 최소 시야는 1 Hex
- 이동 가배치 중에는 새로운 위치의 시야를 즉시 미리 보여준다.
- 이동취소 시 원래 위치의 시야로 돌아간다.
- 대기·공격·기술로 행동이 확정되어야 탐험 기록에 영구 반영된다.
- 턴이 끝나도 이미 탐험한 지역은 기억한다.
- 현재 시야 밖의 적은 화면에서 숨긴다.
- 개발 설정의 지도 안개 체크로 전체 지형을 비교할 수 있다.

## 7. 주둔지 1단계

### 현재 구현

- 주둔지는 도시 성장의 첫 단계이며 영웅의 `주둔지 건설` 명령으로 세운다.
- 최초 주둔지는 수도로 지정한다.
- 영웅은 주둔지를 세운 뒤에도 독립 유닛으로 유지되며 자동 배속되지 않는다.
- 평원과 언덕에 건설할 수 있다.
- 숲·습지·산악·강·백사장·바다에는 건설할 수 없다.
- 같은 세력의 주둔지는 최소 3 Hex 거리를 둔다.
- 주둔지는 주변 2 Hex의 시야를 제공한다.
- 주둔지는 목책·지휘 천막·보조 천막·깃발·보급 상자로 구성된 3D 오브젝트다.
- 카메라 회전 시 지형과 같은 공간에서 함께 회전한다.
- 주둔지가 있는 Hex 정보창에서 도시 단계와 수도 여부를 확인할 수 있다.

### 아직 미구현

- 시설 슬롯, 생산, 방어 수치
- 소도시 이상 성장
- 영웅의 도시 임무 배속
- 영향권 표시와 자원 생산
- 점령과 수도 함락

## 8. 다음 논의 대상: 탐험 목표물

아직 구현하지 않았으며 역할을 확정한 뒤 추가한다.

우선 검토할 후보:

- 중립 마을: 보급, 점령, 도시 성장의 출발점
- 유적: 일회성 사건, 아이템, 연구 또는 위험
- 감시탑: 주변 시야 확대
- 자원 거점: 광산, 목재, 말 등 장기 생산
- 영웅 조우 장소: 영웅 정보와 영입 임무 시작
- 적 야영지: 이동 위협과 전투 보상
- 요새·관문: 주요 길목 통제
- 항구: 해상 이동과 섬 탐험의 출발점

첫 검토 권장 세트는 중립 마을, 유적, 감시탑, 영웅 조우 장소, 적 야영지다.

- 정식 영웅 영입·성장·장비
- 적 세력 전략 AI
- 단계 통일과 다음 세계 계승
- 저장·불러오기 정식 구조
- 과금과 보석
- 계정과 클라우드 저장
- 소셜 공유와 전략 상담

## 10. 개발 협업 경계

- Codex: 월드 생성, 지형 그래픽, 캐릭터 이미지, 지도 상호작용, 최종 통합과 배포
- Claude 작업 영역: `lib/game/**`, `app/game/**`의 게임 규칙과 화면
- 월드와 게임 규칙은 `lib/integration/**`의 어댑터를 통해 연결한다.
- 다른 Hex 좌표 체계나 중복 지형 ID를 만들지 않는다.
- Claude 작업 브랜치는 월드 데이터 계약이 확정되기 전 main에 병합하지 않는다.

- 확정된 기획은 이 문서에 추가한다.
